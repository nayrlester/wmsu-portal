Records module (WMSU CIS)

Local web URLhttp://127.0.0.1:5181
API prefix/api/v1/records on Base API
Platform coderecords

Access

  1. Sign in at WMSU Portal and launch Records (TORMS) when the records platform is assigned.
  2. Identity role records_officer maps to registrar staff capabilities inside TORMS.
  3. Students with the student role may use self-service transcript/certification requests when records platform is granted — not full staff modules.

Staff workflows (summary)

  • Transcript of Records (TOR) requests — intake, validation, issuance
  • Certifications and official document requests
  • Alumni and reporting modules as enabled in your deployment
  • Integration with USiS academic data for student identity and program context
